
# Экспериментальный парсер №7 — Эрмитажный театр

Источник: https://hermitagetheater.ru/afisha

## Запуск

```bash
python -m pip install -r requirements.txt
python parser.py
```

Разбор сохранённой HTML-страницы:

```bash
python parser.py --html-file afisha.html
```

## Результат

`data/sample_output.json` содержит список сеансов. Один сеанс — один
объект `Event` с общими полями команды:

- `title` — название постановки;
- `starts_at` — дата и время `YYYY-MM-DD HH:MM:SS`;
- `venue` — место проведения или `null`;
- `description` — дополнительная информация или `null`;
- `url` — ссылка на постановку;
- `ticket_url` — ссылка на заказ или `null`;
- `tickets` — `link_available`, `none` или `unknown`;
- `source` — `hermitage_7`;
- `collected_at` — время сбора в ISO 8601 с часовым поясом.

Если в афише указано «осталось билетов: 0», `tickets` равно `none`.
Если есть ссылка покупки и нулевой остаток не указан, результат
`link_available`. Число оставшихся билетов в общий JSON не входит.

## Как работает

Парсер ищет ссылки `/repertoire/...` и выделяет блоки с одним
временем и информацией о билетах. Дата определяется из заголовка
карточки или предшествующего заголовка дня. Рекламные слайды
исключаются.

Для повторов используется `event_key()`: при наличии ссылки
`/order/<id>` ключ состоит из источника и ID заказа, иначе — хеш
адреса постановки и даты сеанса.

`data/previous_snapshot.json` хранит результат предыдущего запуска.
Парсер считает новые, изменённые, неизменившиеся и отсутствующие
в текущей выборке сеансы. `collected_at` в сравнении не участвует.
Если найдено менее половины прежнего количества сеансов, состояние
не перезаписывается.

## Ограничения

- Сеансы без распознанного времени и блока билетов пропускаются.
- Изменение количества билетов без изменения статуса не фиксируется.
- Без ID заказа перенос изменит резервный ключ.
- Исчезновение из афиши не доказывает отмену спектакля.
- Реальную структуру HTML необходимо проверить локально перед PR.

# SRC-005: МДТ — Театр Европы (`mdt-dodin_5`)

- **URL источника:** `https://mdt-dodin.ru`
- **Метод получения данных:** Статический HTML (`httpx` + `BeautifulSoup` + `lxml`). Headless-браузер не требуется.

## Запуск

```bash
pip install -r requirements.txt
python parser.py
```

Результат сохраняется в `data/sample_output.json`.

## Особенности источника и ограничения
1. **Статус билетов без цен:** На общей странице афиши доступен только бинарный статус (`available` по кнопке «Купить» или `sold_out`). Количество свободных мест и цены спрятаны во внешнем билетном виджете.
2. **Краткое описание:** В карточке афиши указан только автор/режиссер. Полная аннотация находится на внутренней странице спектакля (`/plays/...`).
3. **Дедупликация и её ограничения:** Используется локальный SQLite (`.state.db`, исключен из git) с ключом `SHA-256(source + title + starts_at + venue)`. Ограничение: при переносе времени показа или изменении текста названия событие определится как новое; возможен «дребезг» статуса при возврате неоплаченных броней.

# SRC-006: Театр музыкальной комедии (`muzcomedy_6`)

- **URL из реестра:** `https://muzcomedy.ru`
- **Фактический источник данных:** `https://muzcomedy.ru` (вся продажа билетов идет через билетный портал).
- **Метод получения данных:** Прямой парсинг XML (`httpx` + `lxml.etree`). Сервер отдает чистый XML с XSLT-шаблоном (`<root><content>...</content></root>`), поэтому браузерный рендеринг не нужен.

## Запуск

```bash
pip install -r requirements.txt
python parser.py
```

Результат сохраняется в `data/sample_output.json`.

## Особенности источника и ограничения
1. **Разделение основного сайта и билетного портала:** Основная афиша на `muzcomedy.ru` ссылается на билетный шлюз `tickets.muzcomedy.ru`, где данные уже структурированы в XML и содержат точное количество свободных мест.
2. **Сессионный атрибут `sid`:** В корневом теге XML генерируется идентификатор сессии; при запросах без cookies портал стабильно отдает общую афишу, но при высокой частоте запросов возможны ограничения.
3. **Дедупликация и её ограничения:** Используется локальный SQLite (`.state.db`, исключен из git) с ключом `SHA-256(source + title + starts_at + venue)`. При переносе времени или изменении формулировки названия событие будет воспринято как новое.

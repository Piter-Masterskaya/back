# Эксперимент: Парсер источника №12 — Петербургский музей парфюмерии

- **Источник:** https://parf-muzey.ru
- **Подход:** Статический HTML с принудительным декодированием байтов из `windows-1251` (`response.content.decode("cp1251")`) + `BeautifulSoup4 (lxml)` + валидация `Pydantic`.

## Запуск и проверка дедупликации

```bash
cd experiments/parf_muzey_12
python -m venv .venv
source .venv/bin/activate  # для Windows: .venv\Scripts\activate
pip install -r requirements.txt
python parser.py
```

- **Первый запуск:** парсер извлекает открытые мероприятия, сохраняет их в `data/sample_output.json`, а их идентификаторы записывает в `data/seen_ids.json`.
- **Повторный запуск:** при повторном вызове `python parser.py` все уже известные события пропускаются с записью в лог (`Пропуск уже известного мероприятия`), а в `data/sample_output.json` попадают только новые. Чтобы заново протестировать полный сбор с нуля, удалите файл `data/seen_ids.json`.

## Особенности источника и выявленные ограничения

1. **Кодировка `windows-1251`:**
   - Сервер отдаёт HTML в кодировке `cp1251`. Стандартное чтение `response.text` в UTF-8 превращает текст в нечитаемые символы (``), поэтому используется явный `response.content.decode("cp1251", errors="replace")`.
2. **Табличная вёрстка без отдельных страниц событий:**
   - Все мероприятия находятся на одной HTML-странице внутри строк `<tr>`. Внешние ссылки на покупку билетов есть лишь у единичных выездных событий (например, лекция в Юсуповском дворце — `tickets.yusupov-palace.ru`), для остальных событий `url` указывает на общую страницу расписания.
3. **Неоднородность строк и «шум»:**
   - В таблице смешаны открытые мероприятия (лекции, МК, выставки) и служебные слоты (`ЗАНЯТО`, `Занято на двоих для А и Е`, `МУЗЕЙ В СПЯЧКЕ!`, `СВОБОДНО ДЛЯ ЗАКАЗА ЭКСКУРСИИ`). Парсер отфильтровывает их по списку стоп-фраз.
   - Год указан только в заголовке месяца (`Ноябрь 2026`, `Декабрь 2026`), а в ячейках даты стоит формат `25.11 Ср`. При переходе через декабрь к январю год инкрементируется программно (проверено на выставке `10.01.2027`).
4. **Цветовая кодировка (ограничение прототипа):**
   - На сайте тип события и статус входного билета дополнительно кодируются цветом фона ячейки (золотистый — Школа парфюмеров, красный — вход свободный). В прототипе классификация опирается на текст ячейки; при переносе в продакшн стоит учитывать также CSS-классы / `bgcolor` ячеек `<td>`.
5. **Дедупликация при повторном запуске:**
   - Поскольку у строк нет уникальных ID или URL, идентификатор строится как SHA-256 от `дата + время + нормализованный заголовок`.
   - **Ограничение:** если администратор вручную поправит опечатку в названии лекции в HTML-таблице, событие будет воспринято как новое.

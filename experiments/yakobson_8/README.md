
# Экспериментальный парсер №8 — Театр балета Якобсона

Источник: https://www.yacobsonballet.ru/afisha

## Запуск

```bash
python -m pip install -r requirements.txt
python parser.py
```

Разбор сохранённой HTML-страницы:

```bash
python parser.py --html-file afisha.html
```

## Результат

`data/sample_output.json` содержит список сеансов. Один сеанс — один
объект `Event` с общими полями команды:

- `title` — название постановки;
- `starts_at` — дата и время `YYYY-MM-DD HH:MM:SS`;
- `venue` — место проведения;
- `description` — описание или `null`;
- `url` — страница постановки или ссылка на афишу;
- `ticket_url` — ссылка на покупку или `null`;
- `tickets` — `link_available`, `none` или `unknown`;
- `source` — `yakobson_8`;
- `collected_at` — время сбора в ISO 8601 с часовым поясом.

`link_available` означает наличие ссылки на покупку, но не наличие
свободных мест. Количество билетов парсер не определяет.

## Как работает

Парсер ищет блоки с одной датой и одним временем, затем извлекает
название, площадку, описание и доступные ссылки. Если необходимые
поля определить не удалось, блок пропускается.

Для проверки повторов используется `event_key()`. Если в URL есть
ID сеанса (`/events/.../<id>`), ключ состоит из источника и этого ID.
Иначе используется хеш названия, даты, времени и площадки.

`data/previous_snapshot.json` хранит результат предыдущего запуска.
Парсер считает новые, изменённые, неизменившиеся и отсутствующие
в текущей выборке сеансы. `collected_at` в сравнении не участвует.
Если найдено менее половины прежнего количества сеансов, состояние
не перезаписывается.

## Ограничения

- Год без явного указания определяется относительно текущей даты.
- При отсутствии ID перенос сеанса изменит резервный ключ.
- Исчезновение из афиши не считается подтверждением отмены.
- Кнопка покупки без обычной ссылки `href` не даёт `ticket_url`.
- Реальные HTML-контейнеры нужно проверить на локальном запуске.
